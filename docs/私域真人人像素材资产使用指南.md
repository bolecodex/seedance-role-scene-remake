私域真人人像素材资产使用指南
警告

开发者接入说明

您接入真人认证和同人认证技术API/H5（本技术服务）前，应当仔细阅读并同意遵守《火山引擎真人认证和同人认证技术服务使用规范》
您使用本技术服务前，应该获取自然人单独同意，并应当以清晰、易懂的方式向自然人充分告知人脸信息处理规则，并确保自然人同意以下内容：
（1）《火山引擎真人认证与同人认证技术服务的人脸信息处理规则》该规则说明火山引擎作为受托技术服务方如何处理和保护自然人的人脸信息；
（2）您自身的用户协议和隐私政策，​应包含人脸信息处理的相关条款。
为确保创作者能充分利用 Seedance 2.0 强大的视频生成能力高效生成视频内容，同时规避 AI 生成内容的潜在风险，方舟推出了私域可信素材库。完成入库的可信素材将进入您的私域素材库，在视频生成中使用。
私域素材库支持录入真人人像素材，通过真人认证从根源锁定肖像权归属，规避后续肖像权纠纷风险；终端客户仅需完成一次授权，后续新增妆造可向同一素材资产组上传同人资产，无需重复真人认证流程。

使用前准备 #
要使用私域素材库的全部功能，您需购买高级创作权益说明包。私域虚拟素材库与真人人像素材库共享容量。具体信息请参考 Seedance 2.0 高级创作权益包购买说明。

使用流程概述 #
真人人像素材库使用流程如下：


Step 1. 创建真人人像素材组（Asset Group）
调用接口生成 H5 认证页链接。支持传入 CallbackURL **** 自定义回调页面链接
（终端用户）通过您自定义的方式访问 H5 认证页链接完成真人认证，点击“完成”按钮后，将打开 CallbackURL 链接。
解析 CallbackURL 拼接参数，获取真人认证结果。如通过真人认证（resultCode 为 10000），调用接口查询该终端客户对应的 Asset Group 的 ID。
Step 2. 上传/管理素材（创建 Assets）
素材资产（Assets）入库时，系统会将上传图像与真人认证采集的基准图像进行面部特征一致性比对，比对通过后方可入库。
可使用Assets API 检索素材 ID、更新素材信息或删除素材。
Step 3. 使用人像素材生成视频
基于校验通过（Active状态）的真人人像素材，使用Asset URI发起视频生成任务。

素材资产库结构说明 #
Asset（素材资产）：一个素材文件（当前支持上传图像、视频、音频），是方舟 Seedance 2.0 系列模型可直接用于推理的可信资产。
Asset Group（素材资产组合）：每个 Asset Group 对应一个真人，该真人的单个素材文件为一个 Asset。
说明

注意

每个Asset Group唯一绑定一个真实人像。素材资产（Assets）入库时，系统会将上传图像与真人认证采集的基准图像进行面部特征一致性比对，如判定素材非同一人物，将无法成功入库。
仅需入库推理需使用的素材资产，不需使用的素材资产请勿入库。
仅可使用已入库素材资产的 Id (Asset ID) 进行视频生成，同一形象未入库素材无法使用。
每个上传的素材资产需经过预处理，可轮询调用 GetAsset 接口查询素材状态（对应参数为 Status），仅当状态变为 Active 后，该素材资产方可用于后续推理使用；若状态为 Failed 则表示处理失败，无法用于后续推理使用。详情可参考：私域真人人像素材资产使用指南（邀测用户版）。

真人人像素材资产 API 列表 #
注意

调用素材资产（Assets）API 接口需使用 Access Key 鉴权，详情参考 获取 API 访问密钥（AK/SK）。
上传素材 （CreateAsset） API 为异步接口，系统处理可能出现排队，导致入库时间增加。不承诺上传时间 SLA。

真人认证及获取 Group ID 接口 #
CreateVisualValidateSession: 拉起端上 H5 活体认证页。
GetVisualValidateResult: 真人认证成功后，获取本次真人认证创建的 Asset Group ID。

Asset 创建接口 #
CreateAsset：创建素材资产。该接口可用于上传个人素材资产，创建素材资产后可利用返回字段中的素材 Id （需处于 **Active 状态）**用于 Seedance 2.0 系列模型生成视频。

Asset (Group) 管理接口 #
ListAssetGroups：查询素材资产组合列表。
ListAssets：查询素材资产列表。
GetAsset：查询素材资产信息。
GetAssetGroup：查询素材资产组合信息。
UpdateAssetGroup：更新素材资产组合信息。
UpdateAsset：更新素材资产信息。
DeleteAsset：删除单个素材资产。
DeleteAssetGroup: 删除指定素材组。

使用教程 #

Step 1. 创建真人人像素材组（Asset Group） #

拉起端上 H5 真人认证页 #
使用 POST CreateVisualValidateSession 接口拉起端上 H5 真人认证页。
终端客户使用H5Link完成真人认证，点击“完成”按钮后，将打开 CallbackURL 链接，您可通过解析 CallbackURL 地址后拼接的 resultCode **** 参数，获取真人认证结果。
终端客户通过真人认证（resultCode 为 10000）后，您可使用 API 返回的 BytedToken 查询该终端客户对应的 Asset Group ID。

说明

注意

该 API 接口需使用 Access Key 鉴权，详情参考 API访问密钥管理。
Access Key 对应账号需具备对应 Project 的 ArkFullAccess 权限。
端上 H5 真人认证页链接有效期为 120 秒，需在 120 秒内完成认证。
在请求中传入：

CallbackURL: 必填，检测结束后将自动跳转至该 URL，并带上真人认证结果信息，包括是否成功以及用于查询 Asset Group ID 的 BytedToken。
ProjectName：指定资源项目名称，默认为 default。一个项目中的资源仅可被该项目下的推理接入点使用，获取项目名称请参考文档。

    sess, _ := session.NewSession(config)

        universal.RequestUniversal{
            ServiceName: "ark",
            Action:      "CreateVisualValidateSession",
            Version:     "2024-01-01",
            HttpMethod:  universal.POST,
            ContentType: universal.ApplicationJSON,
        },
        &map[string]any{
            "CallbackURL": "<CALLBACK_URL>",
            "ProjectName": "default", // Asset Group 将创建在该项目内
        },

    if err != nil {
        return
    }
    if resp == nil {

    }

    fmt.Println(string(respData))
}

Step 2. 上传/管理素材 #

上传素材 #
使用 POST CreateAsset接口上传素材。

说明

注意

每个Asset Group唯一绑定一个真实人像。素材资产（Assets）入库时，系统会将上传图像与真人认证采集的基准图像进行面部特征一致性比对，如判定素材非同一人物，将无法成功入库。
当检测到素材中包含多个人脸时无法入库。
每个上传的素材资产需经过预处理，可轮询调用 GetAsset 接口查询素材状态（对应参数为 Status），仅当状态变为 Active 后，该素材资产方可用于后续推理使用；若状态为 Failed 则表示处理失败，无法用于后续推理使用。
上传素材 （CreateAsset） API 为异步接口，系统处理可能出现排队，导致入库时间增加。不承诺上传时间 SLA。
在请求中提供：

GroupId：必填，素材组合 ID
URL: 必填，图片/视频/音频可访问的 URL。素材文件的具体限制详见 Assets API 参考文档。
以图像资产上传为例，人像资产内容最佳实践：
说明

全身参考图要求

板式：竖版
图片内容：人物全身正面图片

说明

人脸特写图要求

板式： 竖版
图片内容：人物正面无表情特写，肩部以上，人物面部占画面2/3左右

AssetType: 必填，支持上传图片/视频/音频类型素材，需指定为 Image/Video/Audio。
Name: 选填，素材名称，可用于管理素材，如素材文件名。
说明

该字段仅可用于在 ListAssets 接口中模糊搜索素材，不会被带入模型推理。在生成视频时，请勿使用该字段指代素材，请使用“图片 N”、“视频 N”格式进行指代。N 为素材在请求体同类素材中的排序。

ProjectName：选填，指定资源项目名称，默认为 default（大小写敏感）。一个项目中的资源仅可被该项目下的推理接入点使用，获取项目名称请参考文档。
说明

如果请求中不指定 ProjectName，则默认上传素材至 default 项目中。需确保素材和模型推理接入点在同一项目中。

注意：

每次请求上传一个素材文件。
该请求返回素材 ID，可使用 GetAsset API 查看是否上传成功。

查询素材
可使用 POST ListAssets 查询 Assets。

支持根据组合 ID (GroupId)、素材状态（Statuses）和素材名称（Name）查询。筛选出符合所有条件的素材。
支持使用 Name 进行模糊搜索，同时使用 GroupId 精确搜索，便于检索所需的素材。
支持使用 SortBy，SortOrder 对结果进行排序

说明

获取完整的 API 参考文档，请查看私域虚拟人像库 API 参考文档。

常见问题 #

为什么素材上传成功后，无法使用素材生成视频或获取素材信息？ #
素材库按项目（Project）隔离。

在视频生成时，必须使用素材所在项目中的推理接入点进行推理。
如果素材上传成功，但使用获取素材接口获取素材失败，可能是因为调用上传素材(CreateAsset)和获取素材接口时传入了不同的 ProjectName。
ProjectName 默认值为 default，即如果不指定该字段，则默认将资源创建至 default 项目中。
建议在同一个项目中管理素材。
