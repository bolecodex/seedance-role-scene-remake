一、为什么 Seedance 2.0 的提示词要“工程化”
Seedance 2.0 本质上是一个多模态 AI 导演：它同时读你的文字、图片、视频、音频，在内部拆成“空间层”（画面里有什么）和“时间层”（事情如何随时间变化）两个维度来理解和生成画面。
因此，好的提示词不是单纯的“文案型形容”，而是“工程型指令”：谁、在什么场景、做什么动作、镜头怎么运动、按怎样的时间顺序发生，分别喂给空间层和时间层。
配合多参考能力，可以用多张图片锁定角色和场景，用视频参考直接复刻运镜与动作节奏，用音频控制节奏和情绪。这对短剧这种高度依赖角色一致性和分镜节奏的内容形态尤其关键。
二、Seedance 2.0 提示词方法论
万能结构与八个核心要素
经过大量实测，收敛出一套在 Seedance 2.0 上效果较稳的“万能公式”，建议撰写时尽量保持这个顺序：
精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质参数 + 约束条件
按这个顺序写，模型对提示词的解析率显著提升，画面稳定性和一次成功率都比堆砌形容词高得多。
简单来说就是：先锁定“谁”和“在干什么”，再交代“在哪、什么氛围”，然后告诉模型“怎么拍”，最后用风格、画质和约束把结果收紧。
按时间线组织成“分镜脚本”——分镜时序
模型的内部建模是空间–时间解耦的。因此，一个电影感视频的提示词，最理想的形态是“时间轴化分镜”：把视频拆成几个时间段，每一段都写清楚“谁+在哪+做什么+镜头怎么动”。
- 反面案例：“男人在街头紧张地奔跑，画面很有电影感。”
- 正面案例（15 秒追逐戏）：
  - 0–4 秒：街巷侧拍，男人缓慢起跑，带有急促的呼吸感。
  - 5–9 秒：男人撞翻水果摊，镜头快速摇动并给到男人惊恐的特写。
  - 10–14 秒：男人翻过矮墙消失，镜头缓慢拉远定格在空荡的街道。
实操建议：对每一段视频都写一个简单的“0–5 秒 / 5–10 秒 / 10–15 秒”分镜，再翻译成完整句子的提示词，而不是一口气写一大段无结构的剧情描述。
动作与运镜的写法
- 动作：
  1. 优先写缓慢、连续的小动作（如：缓慢行走、轻轻抬手、微微低头、顺势坐下），尽量避免“狂奔、大跳、剧烈翻滚”等高强度动作。
  2. 写出动作间的过渡（如：借着刚才转身的惯性、从停顿自然过渡到举手），这有助于模型判断连贯性。
  3. 情绪外化：用“嘴角颤抖、眼眶渐红、肩膀微微抖动”这类身体信号，替代“很悲伤”“非常愤怒”这类抽象情绪词。
- 运镜：Seedance 对中文运镜词理解力很强，直接写“中景、特写、全景、缓慢推镜、平稳横移、固定镜头”即可。注意：一个镜头里尽量只指定 1 种运镜方式，不要同时要求推拉摇移，会增加画面的不稳定性。
画质、风格与约束词
- 画质与风格（放在句末收紧效果）：“高清，细节丰富，电影质感，色彩自然，光影柔和”等。风格词（如：赛博朋克冷蓝紫色调、复古胶片、日系清新）能让关键帧向特定美学靠拢。
- 约束词（极其重要）：尤其对人像和角色类短剧/影视场景，建议结尾固定加上：“面部稳定不变形、五官清晰、人体结构正常、动作自然流畅、不僵硬、画面无卡顿、无闪烁”。这能显著降低变脸、掉脸和抖动的概率。
三、多参考能力：如何用好图片 / 视频 / 音频
Seedance 2.0 的全能参考模式允许用户同时上传多种素材，并用 @ 语法给每个素材指定职责。
素材角色划分与文件数策略
通常把素材分成四种“功能角色”：
1. 角色锚定（锁定角色外观）
2. 场景定调（锁定环境与风格）
3. 运镜参考（锁定镜头语言与动作节奏）
4. 节奏氛围（用音频控制情绪、音色）
注意不要用满上限。过多的素材会让模型难以判断优先级。
稳妥的配置是：角色图 1-2 张（正脸/全身）+ 场景图 1 张 + 运镜视频 1 段 + 音频 1 段（总计 4-5 个素材）。
@ 语法写法：基础与进阶
多参考模式下，@ 语法是你和模型的“导演指令”。如果不写，模型只能靠猜，成功率极低。
- 基础写法（声明用途）：“@图片1 作为角色参考，@图片2 作为场景参考，@视频1 参考运镜和动作节奏，@音频1 作为背景音乐。接下来……”
- 进阶写法（绑定时间轴）：“@图片1 为角色外观。0–3 秒角色背对镜头站立，镜头缓慢环绕；3–8 秒角色转身，参考 @视频1 的运镜方式；8–15 秒镜头快速拉远展现全景，配合 @音频1 的鼓点。”
避坑点：当有多个人物或视频时，必须明确对应关系。例如：“@图片1 的女生为女主，@图片2 的男生为男二，@视频1 仅用于学习镜头运动轨迹，不要复刻其中的人物和场景”。
多镜头角色一致性与跨段衔接
- 单段内：只要每次生成都引用同一张角色参考图，并在文字里保持主体描述一致，角色一致性就能得到保证。建议加上“基于 @图片1 保持角色外观、服装、发型一致”。
- 长于 15 秒的视频素材：
  1. 视频延长：把上一段生成的视频作为 @视频1 输入，并写“将 @视频1 向后延长 N 秒，保持角色外观、背景和光线与前段完全一致”。适合 30–45 秒内的连续场景。
  2. 分段拼接：把整段剧情拆分成多个 10–13 秒的小片段独立生成，但统一使用同一套角色图、场景图与提示词模板。最后在剪辑软件里拼接。
四、视频编辑能力的提示词方法
视频延长与连续镜头衔接
实施方法：将已经生成好的15s视频作为新的参考素材，例如“ @视频1 输入”，然后在提示词中明确指示：“将 @视频1 的内容向后平滑延长 10 秒，保持角色、场景、光影风格与前段完全一致。”
与分段拼接的协同：
- 连续长镜头：当一个场景内的核心动作或对话需要一镜到底时，优先使用“视频延长”。例如，角色从房间一头走到另一头的完整过程。
- 场景切换/大跨度动作：当剧情发生转折，或需要表现快速、复杂的动作时，“分段拼接”依然是最佳选择。先独立生成各个小片段，再用剪辑软件组合。
用法策略：何时延长，何时拼接？
- 延长：适用于“文戏”，如长对话、情绪的缓慢积累、单一路径的移动等，追求的是沉浸感和连贯性。
- 拼接：适用于“武戏”，如追逐、打斗、快速蒙太奇等，追求的是节奏感和视觉冲击力。
在实际制作中，通常是两种方法的结合。例如，先用“延长”做完一段 30 秒的室内对话，再“拼接”一个 5 秒的窗外风景空镜。
局部修改与内容重绘
- 核心能力：
  - 角色更替：在保持场景和其他演员不变的情况下，将 A 角色替换为 B 角色。
  - 道具/背景微调：为角色手上的杯子换个颜色，或擦除背景中一个穿帮的路人。
  - 瑕疵修复：修正生成视频中偶尔出现的轻微面部抖动、肢体变形或光影跳跃。
- 提示词写法：关键在于“绑定时间轴与空间层”。你需要精确告诉模型在哪个时间段、哪个区域进行修改。
提示词片段示例：局部替换
场景：一段已生成的 10 秒视频（@视频1），其中女主穿着蓝色外套。现在需要将其换成红色。
提示词：
“基于 @视频1 进行编辑。在 0-10 秒 的整个时间轴内，将画面中主角身上的蓝色外套替换为红色外套。保持人物的面部、发型、动作以及背景环境、光线完全不变。最终成片需确保色彩过渡自然，无闪烁或边缘破绽。”
首尾帧控制&多参考结合
精确控制视频的开场和收尾，是提升短剧“电影感”的关键。通过“首帧/尾帧约束”，可以强制视频的开始或结束画面与指定的参考图保持高度一致，从而实现稳定的风格、统一的主体和紧凑的节奏。
- 首帧约束：使用 @图片1 作为首帧，确保视频的开场画面在构图、角色姿态和场景氛围上与参考图对齐。这对于系列短剧的风格统一至关重要。
- 尾帧约束：使用 @图片2 作为尾帧，可以让镜头的落点精准收在一个设计好的画面上，常用于制造悬念或完成一个抒情段落，实现节奏收紧。
- 首尾帧约束与多参考能力结合：
  - @角色图 + @场景图 + @首帧图：保证了开篇的角色、环境和构图的稳定。
  - @运镜视频 + @音频 + @尾帧图：控制了过程的动态节奏和结尾的静态构图。
五、短剧提示词-三段论写法实战示例
你可以将以下模板抽象成“整体设定 + 时间片分镜 + 风格画质约束”的结构。
示例一：都市情感短剧-宿舍场景（偏文戏/对话）
素材准备：
- @图片1：女主半身照
- @图片2：宿舍场景参考图
- @视频1：室内对话运镜参考（中景推拉或轻微摇移）
- @音频1：室内环境声或轻音乐
提示词：
@图片1 中的女孩作为主角，@图片2 作为宿舍场景风格参考，参考 @视频1 的运镜方式。
0–5 秒：傍晚时分，女孩脚步轻快地走到宿舍门口，镜头中景平稳跟拍，暖黄色日光从窗外洒进走廊，她在门口停顿一下，深呼吸，表情略带紧张。
5–10 秒：她推开门走进宿舍，镜头切到室内中景，舍友们一边整理书本一边抬头看向她，其中一人笑着问‘考得怎么样呀，过了吗？’，镜头在几人之间缓慢切换半身特写。
10–15 秒：女孩先低头露出落寞表情，镜头给到她的近景，随后她抬头憋不住笑意，哈哈大笑说‘骗你们的’，舍友们追着打闹起来，镜头缓慢拉远，定格在宿舍内一片欢声笑语的全景画面。
全程画面 4K 高清，电影纪实风，色调温暖，光影柔和；人物面部稳定不变形，动作自然流畅，无卡顿无闪烁；环境音效与 @音频1 自然融合。

- @图片2：黑衣刺客（对手）

整体画面烟雨江湖电影感，冷调低饱和，电影胶片质感，光影层次丰富；人物面部和身体比例稳定不变形，动作连贯自然，不僵硬，无穿模无卡顿。
六、善用VLM模型反推提示词
挑战&目标
围绕正面多人物&镜头移动的人脸替换场景，视频中不同的人都有自己的神态、表情、动作、甚至台词，很多变化是瞬时的，如果让模型直接基于像素人姿势+单一正面静帧+强编辑指令视频易出现某人物跳脸、人物细节变化、及一致性保持不好的问题，同时再伴有音频参考就更有难度了
方法
- 运用VLM视觉理解模型对视频/图片进行理解，若需反推视频提示词，在提示语（prompt）中要求模型描述空间内人物的位置关系以及每个人的关键特征，并告知模型“若要生成这样一个视频，请协助反推出提示词，需明确写出全局基础设定、分镜时序、约束条件”。
- 静帧参考图准备：借助seedream 5.0 Lite，将几张正面静帧替换为外国籍人士的面部以及物品细节、环境细节等内容。
- 姿势动作参考视频准备：以原视频为基础，使用sdpose生成参考姿势像素人视频，或者准备参考姿势视频。
PE示例
（输入视频给seed-2.0-pro 260215)，文字prompt：如果我要生成这样一个视频，帮我反推出提示词，需明确写出全局基础设定、分镜时序、约束条件
一、全局基础设定
1. 场景属性：同世界观下的国际航天联合岗前培训场地，背景为纯色工业绿幕，前方设投影幕布与教学黑板，受训人员统一坐在塑料折叠椅上，整体为冷调工业风。
2. 人物设定：讲师欧洲男性，穿灰蓝色作训服、蓝色贝雷帽、头戴通讯耳麦；学员为多国航天受训者，统一穿着浅白色工装、佩戴白色工作帽与通讯耳麦，部分学员手臂印有所属国国旗臂章，全员背对镜头朝向投影方向。
3. 视觉风格：硬核科幻现实主义，低饱和冷青灰调色，光线偏柔和偏暗，整体氛围严肃正式，符合职业培训的质感。
4. 核心主题：深空探索安全警示教育课堂上，学员举手示意后离场，讲师回应后继续讲解事故案例。
二、分镜时序
1. 0.0-5.0s：镜头采用浅景深，焦点锁定前景学员举起的手臂，手臂处清晰显示巴西国旗臂章，背景的其他学员、讲师、投影幕均处于虚化状态；学员保持举手姿态数秒后放下手臂，起身离开座位。
2. 5.0-8.0s：镜头焦点顺滑后移，整个培训教室清晰呈现，举手学员已离开画面，此时投影幕为白屏状态，讲师坐在学员侧前方的折叠椅上，转头看向学员离场的方向。
3. 8.0-11.0s：投影切换为面部灼伤的遇难宇航员黑白遗像，讲师点头示意后转头看向投影，学员们保持注视投影的状态。
4. 11.0-13.5s：讲师从椅子上起身，走到投影幕旁站立，此时投影内容切换为宇航服内受伤宇航员的特写画面，讲师面向投影准备继续讲解。
三、约束条件
1. 运镜要求：全程固定机位，仅做焦点前后切换，焦点过渡自然顺滑，符合真实相机浅景深对焦逻辑，无推拉摇移等额外运镜。
2. 风格统一：全程保持低饱和冷调，投影内容均为黑白纪实风格，无高饱和暖色元素，画面质感与同系列培训场景完全一致。
3. 动作逻辑：学员举手、放下、离场的动作符合课堂申请离场的正常流程，讲师的回应、起身、走到投影旁的动作自然流畅，无夸张表演痕迹。
4. 细节一致性：所有人物服装、配饰无穿帮，人物臂章清晰准确，投影内容符合深空事故伤情特征，背景绿幕保持纯色无杂色，光影统一来自投影光源，无额外奇怪光源。
高频 Badcase 和优化方法
1.未正确定义Asset ID和输入参考关系
从模型视角看，Asset ID是一个风控准入的身份ID，不是一个从参考调用视角的一一映射关系。
使用Asset时，模型不会把assert和输入的参考内容直接对应上，需要用户自己从图1，视频1等写清楚两者对应关系。
举例错误用法：
"content": [
         {
            "type": "text",

2.多人场景人物数量出错
多人场景属于复杂生成任务，模型需要同时满足多项常识与结构条件，生成难度更高，可能需要多次生成才能得到符合要求的结果多人场景。下面的方法有助于降低抽卡次数。
- 检查提示词是否出现歧义：若存在歧义，会导致视频生成效果不佳。
【优化前】
“@图片3是美女3……美女3位于画面左下后景，美女4位于……”
提示词中“美女3位于画面左下后景”时，模型会以为是“美女3位于画面左下后景”。断句位置引发歧义，导致每次尝试生成时，人物数量都可能不同。
【优化后】
“@图片3是美女C……美女C位于画面左下后景，美女D位于……”
- 清晰描述人物在不同图中的对应关系：尽可能在提示词中描述清楚人物的背景信息、多人场景参考图和单人参考图之间同一人物的对应关系。
【优化前】

未说明图片1的人物和图片3的对应关系
